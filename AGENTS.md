# StayQR Project Instructions

## Project
StayQR is a production-ready multi-hotel hospitality SaaS.

## Current Phase
Pilot Launch

## Locked Roadmap

1. Professional PDF Invoice
2. Google Review & Rewards
3. RLS Security
4. Production Deployment
5. Staff Authentication & Role-Based Dashboards

## Rules

- Never change roadmap order without asking.
- Always inspect existing code before making changes.
- Never remove working features.
- Always preserve the multi-hotel architecture.
- Use getCurrentHotel() wherever hotel isolation is required.
- Prefer complete copy-paste file updates instead of partial snippets.
- Do not create duplicate components if one already exists.
- If unsure, ask before changing architecture.
