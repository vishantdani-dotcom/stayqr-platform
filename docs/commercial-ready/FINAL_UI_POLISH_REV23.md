# StayQR Final UI Polish REV23

## Objective
Make the staff/admin product feel modern, efficient, trustworthy, advanced and professional while preserving every operational workflow and the already accepted REV22 functional state.

## Visual corrections
- Replaces legacy gold/warm admin emphasis with a cool blue/steel operational accent.
- Makes sidebar selection, tabs, links, buttons, focus states and form controls consistent.
- Fixes Housekeeping checklist controls with a custom accessible checkbox that does not depend on a brittle parent selector.
- Removes the bright green checkbox fill and uses a restrained blue checked state with a crisp white SVG checkmark.
- Polishes legacy inline-styled modules such as Charges and Hotel Profile without altering their data logic.
- Neutralises Media Manager controls while preserving uploaded hotel media.
- Polishes login/authentication presentation and responsive collapse.
- Adds responsive spacing, touch targets, table containment and form-grid fallbacks for tablet/mobile.
- Preserves semantic success/error states and leaves guest-facing Guest Guide / Food pages out of scope.

## Safety
Presentation-only CSS plus one stylesheet import. No database migration. No provider configuration. No production deployment. No Meta or Cashfree changes.
