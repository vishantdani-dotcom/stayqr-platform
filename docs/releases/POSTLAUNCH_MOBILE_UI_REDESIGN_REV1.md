# StayQR Post-Launch Mobile UI Redesign REV1

## Scope
Presentation-only responsive redesign for the authenticated StayQR workspace.

## Targets
- 390px phones
- 430px large phones
- tablet portrait
- desktop behavior remains unchanged

## Key changes
- mobile app shell, safe gutters, touch targets and off-canvas navigation
- compact two-column metric cards
- stacked/scrollable action bars and tabs
- Dashboard mobile command-centre layout
- Rooms register rendered as phone-friendly cards
- Guest Directory rendered as phone-friendly CRM cards
- Staff identities rendered as mobile cards
- Operations Centre compact mobile workspace
- Super Admin mobile control-centre layout and bottom-sheet dialogs

## Contracts
No database, API, authentication, RLS, tenant, Git or deployment contract changes.
Production is not part of this patch.
